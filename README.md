# Sistema para pequenos negócios

> **Nome provisório.** A pasta pode ser renomeada sem prejuízo — nada depende dela ainda.

Sistema de gestão e escrituração para **pequenos negócios** (ex.: loja de roupa), para uso
próprio do dono, cuidando da parte contábil e gerencial de clientes pequenos.

**Status: não iniciado.** Só existe o documento de partida.

## Comece por aqui

👉 **[docs/00_NORTE.md](docs/00_NORTE.md)** — o que é, o que dá pra reaproveitar do
ContLife, e as perguntas de escopo que precisam ser respondidas antes de escrever código.

## Relação com o ContLife

Projeto **independente** — pasta própria, git próprio, banco próprio. O
[ContLife](../sistema%20financeio) (finanças pessoais, já no ar em beta) é **fonte de
reaproveitamento**: motor contábil, backend multiempresa, autenticação e sistema visual
saem de lá. Copiados para cá, não importados — este sistema não pode quebrar se o ContLife
mudar.

⚠️ **Não alterar a pasta do ContLife.** Ele está em produção.
